# ✈️ AI Travel Booking Agent

An intelligent, full-stack AI travel agent built using **FastAPI**, **Gemini Flash**, and **Next.js**.

## 🏗️ Tech Stack
- **Frontend:** Next.js, Tailwind CSS
- **Backend:** FastAPI (Python)
- **AI Engine:** Google Gemini 1.5 Flash API (Structured JSON Mode)
